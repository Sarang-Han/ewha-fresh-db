# 📅 학사일정 프론트엔드 연동 및 메인 화면 표출 가이드

이 문서는 이화여대 신입생 학사 챗봇 시스템에서 **학사일정 CSV 데이터를 활용하여 프론트엔드 메인 화면에 최근 일정을 성공적으로 연동 및 표출할 수 있도록** 현재 시스템 구조를 설명하고 구체적인 구현 방안을 제시하는 개발 가이드입니다.

---

## 1. 현재 상황 분석 및 문제 진단

### 🐻 챗봇 질문(2026 일정)이 잘 작동하는 이유
사용자가 "2026년 개강일이 언제야?"와 같은 질문을 하면, 시스템은 다음과 같이 정상적으로 작동합니다:
1. **Intent 분류**: `app/intent_router.py`가 질문을 `Intent.SCHEDULE`로 분류합니다.
2. **CSV 로드**: `app/csv_loader.py`가 `data/official/학사일정/` 폴더 내의 모든 `academic_calendar_*.csv` 파일을 병합하여 메모리에 탑재하고 있습니다.
3. **LLM 컨텍스트 전달**: `app/schedule_pipeline.py`에서 로드된 학사일정 CSV 전체 텍스트와 수강신청 CSV를 LLM(Gemini)에 함께 전달하고, 프롬프트를 통해 필터링 및 답변을 유도하여 이쁜 마크다운 답변을 생성합니다.

### ❌ 메인 화면에서 최근 일정을 띄우지 못하는 이유
챗봇 대화는 LLM이 전체 CSV 텍스트를 파싱해서 동적으로 답해주지만, **메인 화면의 위젯(최근 일정 컴포넌트)은 정형화된 JSON 데이터를 백엔드로부터 직접 받아와서 직접 렌더링해야 합니다.**
현재 백엔드(`app/main.py`)에는 다음과 같은 한계가 있어 프론트엔드 연동이 불가능한 상태입니다:
1. **학사일정 조회 API 부재**: 현재 API 엔드포인트는 `GET /`, `GET /health`, `POST /ask`(챗봇용)만 존재하며, 학사일정 CSV 데이터를 구조화된 형태로 조회할 수 있는 전용 API 엔드포인트가 없습니다.
2. **정적 파일 접근 제한**: 프론트엔드가 백엔드 서버에 직접 CSV 파일(`academic_calendar_2026.csv`)을 HTTP GET으로 요청하여 자체 파싱하려 해도, FastAPI에서 `data/` 디렉토리에 대한 정적 파일(Static Files) 서빙 경로가 마운트되어 있지 않아 직접 접근할 수 없습니다.

## 2. 현재 백엔드 학사일정 데이터 구조

### 데이터 파일 정보
* **위치**: `data/official/학사일정/`
* **대상 파일**:
  - `academic_calendar_2025.csv` (2025학년도 일정)
  - `academic_calendar_2026.csv` (2026학년도 일정)
  - `calendar_schema.md` (스키마 설명 문서)

### CSV 데이터 스키마 (`calendar_schema.md` 기반)
학사일정 CSV 파일은 다음과 같은 정형화된 컬럼으로 구성되어 있습니다:

| 컬럼명 | 데이터 타입 | 설명 | 예시 값 |
| :--- | :--- | :--- | :--- |
| **academic_year** | `int` | 학년도 | `2026` |
| **start_date** | `str (YYYY-MM-DD)` | 일정 시작일 | `2026-03-03` |
| **end_date** | `str (YYYY-MM-DD)` | 일정 종료일 | `2026-03-03` |
| **semester** | `str` | 학기 정보 (`1`, `2`, `summer`, `winter`) | `1` |
| **event_type** | `str` | 일정 유형 (분류용 태그) | `semester_start` |
| **title_raw** | `str` | 공식 행사 명칭 (한국어 원문) | `1학기 개강` |
| **target** | `str` | 대상 학생군 (`신입생`, `재학생`, `전체` 등) | `전체` |
| **is_holiday** | `int (0 또는 1)` | 공휴일 여부 (`1`: 공휴일, `0`: 평일/기타) | `0` |
| **notes** | `str` | 비고 (특이사항, 예외 규정 등) | `(비어있을 수 있음)` |

> **실제 CSV 데이터 예시 (`academic_calendar_2026.csv`):**
> ```csv
> academic_year,start_date,end_date,semester,event_type,title_raw,target,is_holiday,notes
> 2026,2026-02-19,2026-02-20,1,course_registration,2026학년도 1학기 신입생 수강신청,신입생,0,
> 2026,2026-03-03,2026-03-03,1,semester_start,1학기 개강,전체,0,
> 2026,2026-03-03,2026-03-09,1,course_change,1학기 수강신청 확인 및 변경,전체,0,
> ```

## 3. 해결 방안 1: 학사일정 JSON API 엔드포인트 구현 (강력 추천)

가장 우수하고 안전한 방법은 백엔드에 **학사일정 데이터를 JSON 배열로 가공하여 반환하는 전용 API 엔드포인트**를 추가하는 것입니다. 백엔드는 서버 시작 시 이미 CSV 데이터를 메모리에 로드하고 있으므로, 이를 파싱하여 제공하는 아주 가볍고 효율적인 API를 구성할 수 있습니다.

### 단계 1: Pydantic 응답 모델 생성 (`app/models.py`에 추가)
프론트엔드가 받을 데이터의 타입을 명확히 정의하고 자동 문서화(Swagger)를 활용하기 위해 모델을 정의합니다.

```python
# app/models.py 파일 하단에 추가

class CalendarEventResponse(BaseModel):
    """학사일정 개별 이벤트 모델"""
    academic_year: int = Field(..., description="학년도")
    start_date: str = Field(..., description="시작일 (YYYY-MM-DD)")
    end_date: str = Field(..., description="종료일 (YYYY-MM-DD)")
    semester: str = Field(..., description="학기 (1, 2, summer, winter)")
    event_type: str = Field(..., description="이벤트 타입")
    title_raw: str = Field(..., description="일정명")
    target: str = Field(..., description="대상")
    is_holiday: bool = Field(..., description="공휴일 여부")
    notes: Optional[str] = Field(None, description="비고")
```

### 단계 2: API 엔드포인트 추가 (`app/main.py`에 추가)
CSV 텍스트를 읽어 JSON 형식으로 파싱하고, 필터링 및 조회가 가능한 API 엔드포인트를 라우터에 등록합니다. Python의 내장 `csv` 모듈과 StringIO를 활용하여 초고속으로 메모리 내 CSV 데이터를 파싱합니다.

```python
# app/main.py 상단 임포트문에 추가
import csv
from io import StringIO
from typing import List, Optional
from app.models import CalendarEventResponse # 새로 생성한 모델 임포트

# app/main.py 하단에 API 엔드포인트 추가
@app.get("/api/calendar", response_model=List[CalendarEventResponse])
async def get_academic_calendar(
    year: Optional[int] = None, 
    event_type: Optional[str] = None,
    upcoming: bool = False
):
    """
    학년도 및 일정 유형별로 필터링된 학사일정 목록을 조회합니다.
    
    Args:
        year: 조회할 학년도 (예: 2026)
        event_type: 필터링할 이벤트 타입 (예: course_registration, holiday 등)
        upcoming: True로 설정 시, 오늘 날짜(또는 현재 기준) 이후에 종료되는 일정만 반환합니다.
    """
    try:
        # csv_loader에서 이미 병합 완료된 학사일정 CSV 텍스트 가져오기
        csv_texts = get_csv_texts()
        calendar_csv = csv_texts.get("academic_calendar", "")
        
        if not calendar_csv:
            raise HTTPException(status_code=404, detail="학사일정 데이터를 찾을 수 없습니다.")
        
        # CSV 데이터 파싱
        f = StringIO(calendar_csv.strip())
        reader = csv.DictReader(f)
        
        events = []
        today_str = datetime.now().strftime("%Y-%m-%d")
        
        for row in reader:
            # 1. 학년도 필터
            if year and int(row["academic_year"]) != year:
                continue
                
            # 2. 이벤트 타입 필터
            if event_type and row["event_type"] != event_type:
                continue
                
            # 3. 최근/다가오는 일정 필터 (오늘 날짜 기준 end_date가 지나지 않은 일정)
            if upcoming and row["end_date"] < today_str:
                continue
                
            events.append(CalendarEventResponse(
                academic_year=int(row["academic_year"]),
                start_date=row["start_date"],
                end_date=row["end_date"],
                semester=row["semester"],
                event_type=row["event_type"],
                title_raw=row["title_raw"],
                target=row["target"],
                is_holiday=row["is_holiday"] == "1" or row["is_holiday"].lower() == "true",
                notes=row["notes"] if row["notes"] else None
            ))
            
        # 날짜 오름차순 정렬 (시작일 기준)
        events.sort(key=lambda x: x.start_date)
        
        return events
        
    except Exception as e:
        logger.error(f"학사일정 데이터 파싱 실패: {str(e)}")
        raise HTTPException(status_code=500, detail=f"학사일정을 불러오는 중 오류가 발생했습니다: {str(e)}")
```

## 4. 해결 방안 2: FastAPI 정적 파일 마운트 (CSV 직접 다운로드)

만약 백엔드 코드 수정 없이 **프론트엔드 브라우저단에서 직접 CSV 파일을 다운로드받아 프론트엔드 라이브러리(예: `papaparse`)를 사용해 직접 파싱**하고 싶다면, 백엔드의 `data/official/` 폴더를 정적 디렉토리로 개방해야 합니다.

### 구현 방법 (`app/main.py`에 추가)
```python
from fastapi.staticfiles import StaticFiles

# CORS 설정 아래 혹은 app 정의 근처에 추가
# 프론트엔드에서 http://localhost:8000/static/학사일정/academic_calendar_2026.csv 형태로 접근 가능
```

## 5. 프론트엔드 구현 예시 (React + TypeScript)

제안드린 **해결 방안 1(API 엔드포인트)**을 적용한 경우, 프론트엔드 메인 페이지에 최신 일정을 띄우는 완전한 React 구현 컴포넌트 예제입니다.

### 1. TypeScript 인터페이스 정의
```typescript
export interface CalendarEvent {
  academic_year: number;
  start_date: string;
  end_date: string;
  semester: string;
  event_type: string;
  title_raw: string;
  target: string;
  is_holiday: boolean;
  notes?: string;
}
```

### 2. 메인 페이지 일정 위젯 컴포넌트 (`MainCalendarWidget.tsx`)
```tsx
import React, { useEffect, useState } from 'react';
import { CalendarEvent } from './types';

const BACKEND_URL = 'http://localhost:8000'; // 백엔드 주소

export const MainCalendarWidget: React.FC = () => {
  const [events, setEvents] = useState<CalendarEvent[]>([]);
  const [loading, setLoading] = useState<boolean>(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    // 다가오는(upcoming=true) 2026년도 일정을 백엔드에 요청
    const fetchSchedules = async () => {
      try {
        setLoading(true);
        const response = await fetch(`${BACKEND_URL}/api/calendar?year=2026&upcoming=true`);
        if (!response.ok) {
          throw new Error('학사일정을 가져오는데 실패했습니다.');
        }
        const data: CalendarEvent[] = await response.json();
        
        // 메인 화면에 너무 많은 일정을 노출하지 않기 위해 상위 5개만 슬라이스
        setEvents(data.slice(0, 5));
      } catch (err: any) {
        setError(err.message || '네트워크 오류가 발생했습니다.');
      } finally {
        setLoading(false);
      }
    };

    fetchSchedules();
  }, []);

  if (loading) return <div className="p-4 text-center text-gray-500">🐻 버디가 일정을 불러오는 중이야...</div>;
  if (error) return <div className="p-4 text-center text-red-500">⚠️ 에러: {error}</div>;
  if (events.length === 0) return <div className="p-4 text-center text-gray-500">🎉 당분간 잡혀있는 다가오는 일정이 없어!</div>;

  // 날짜 포맷 변환용 헬퍼 함수
  const formatDateRange = (start: string, end: string) => {
    const sDate = new Date(start);
    const eDate = new Date(end);
    
    const startFormatted = `${sDate.getMonth() + 1}/${sDate.getDate()}`;
    if (start === end) {
      return startFormatted;
    }
    const endFormatted = `${eDate.getMonth() + 1}/${eDate.getDate()}`;
    return `${startFormatted} ~ ${endFormatted}`;
  };

  return (
    <div className="bg-white rounded-2xl shadow-md p-6 max-w-md border border-emerald-100">
      <div className="flex items-center justify-between mb-4">
        <h2 className="text-lg font-bold text-emerald-900 flex items-center gap-2">
          📅 다가오는 이화 학사일정
        </h2>
        <span className="text-xs bg-emerald-50 text-emerald-700 px-2 py-1 rounded-full font-semibold">
          2026학년도
        </span>
      </div>
      
      <div className="space-y-4">
        {events.map((event, index) => (
          <div 
            key={index} 
            className={`flex items-start gap-3 p-3 rounded-xl transition-all hover:bg-emerald-50/30 ${
              event.is_holiday ? 'bg-red-50/40 border-l-4 border-red-400' : 'bg-gray-50/50 border-l-4 border-emerald-500'
            }`}
          >
            {/* 날짜 배지 */}
            <div className="min-w-[70px] text-center bg-white shadow-sm rounded-lg py-1 px-2 border border-gray-100">
              <span className="text-xs font-bold block text-gray-400 uppercase">
                {event.is_holiday ? '휴일' : event.event_type.substring(0, 8)}
              </span>
              <span className={`text-sm font-extrabold ${event.is_holiday ? 'text-red-500' : 'text-emerald-800'}`}>
                {formatDateRange(event.start_date, event.end_date)}
              </span>
            </div>

            {/* 일정 상세 */}
            <div className="flex-1 min-w-0">
              <h3 className="font-semibold text-sm text-gray-800 truncate" title={event.title_raw}>
                {event.title_raw}
              </h3>
              <p className="text-xs text-gray-500 mt-0.5 flex items-center gap-1.5">
                <span>대상: <strong className="text-gray-700">{event.target}</strong></span>
                {event.notes && (
                  <>
                    <span className="text-gray-300">|</span>
                    <span className="truncate text-amber-600 font-medium" title={event.notes}>💡 {event.notes}</span>
                  </>
                )}
              </p>
            </div>
          </div>
        ))}
      </div>
    </div>
  );
};
```

### 3. 화면 배치 팁
* **메인 대시보드 사이드바**나 **웰컴 그리드** 영역에 배치하여, 로그인한 학생의 학년/전공에 맞춰 백엔드 파라미터 필터링(예: `target`)과 결합해 맞춤형 일정을 띄워주면 더욱 좋습니다!
* `upcoming=true`를 주어 오늘 날짜 기준 이미 지난 과거의 일정은 자동으로 걸러지고, 가장 근접한 미래 일정이 상단에 노출되도록 디자인되어 있어 유용합니다.

프론트엔드와 백엔드가 한 팀으로 조화롭게 일하기 위한 가장 깔끔한 연동 절차는 다음과 같습니다:

1. **[백엔드]**: 이 문서 **3번 섹션**의 `app/models.py` 응답 객체 정의 및 `app/main.py`에 `/api/calendar` API 라우트를 추가합니다.

3. **[프론트엔드]**: 제공된 **5번 섹션**의 React 컴포넌트 예시를 활용해 메인 화면 대시보드에 학사일정 컴포넌트를 붙입니다.

이 가이드를 따라 연동하면, 현재 챗봇에서만 똑똑하게 읽고 답변하던 최신 2026 이화 학사일정 고정 데이터를 **메인 대시보드 화면에서도 실시간으로 가공 없이 아름답게 동적 위젯으로 표출**할 수 있습니다!
